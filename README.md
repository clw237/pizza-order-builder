# Pizza Order Builder

A pizza order builder (web UI) and a separate order service, built as a 3-hour take-home exercise.

## Prerequisites

Node.js 22.12 or later.

## Commands

- Install: `npm install`
- Check everything (format, lint, types, tests): `bash scripts/check.sh`

The full README (run commands, API, assumptions, design write-up, AI usage) is written at the end
of the exercise.

Built from the claude-starter template (see `docs/TEMPLATE.md`).
